# Brewing Station Art Set

Generated and revised with the built-in Codex image generation tool plus local palette processing for the gothic brewing station redesign.

Target style: the shop-front scene's dreamy oil-painted gothic mood, with the existing brewing-station composition preserved for gameplay.

Strict palette:
- `#120918` ink black
- `#281235` deep violet
- `#4B1E52` bruised purple
- `#6D1F2B` oxblood
- `#B6423A` muted ember red
- `#8A6232` aged brass
- `#B58A5A` dim parchment
- `#3F5F3D` restrained herb green

Files:
- `brewing_station_background_bright.png`: gothic station background plate.
- `brewing_station_background_bright_shelf_v2.png`: gothic station background plate with the left ingredient shelf rebuilt into five uniform open compartments.
- `book_closed_bright.png`: transparent closed book prop.
- `scales_bright.png`: transparent aged-brass scales prop.
- `mortar_pestle_bright.png`: transparent violet-stone mortar/pestle prop.
- `ingredient_jar_overlay_bright.png`: transparent reusable gothic ingredient jar slot overlay.
- `potion_card_overlay_bright.png`: transparent reusable gothic potion card slot overlay.

Chroma-key sources are kept in `Sources/` so the alpha outputs can be regenerated if needed.
